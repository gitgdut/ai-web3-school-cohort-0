# Handbook Feedback

本目录收集学习过程中对 [AI × Web3 School Handbook](https://aiweb3.school/zh/handbook/) 的反馈。

## 反馈类型

- 🐛 **错别字 / 格式问题**
- ❓ **概念不清 / 解释不足**
- 📅 **资料过期 / 链接失效**
- 💡 **补充建议 / 案例请求**
- 🔧 **结构建议**

## 提交规范

每条反馈一个文件，命名：`YYYY-MM-DD-简短描述.md`

文件模板：

```markdown
# [简短标题]

- **日期**：YYYY-MM-DD
- **类型**：🐛 / ❓ / 📅 / 💡 / 🔧
- **Handbook 页面**：[链接]
- **发现课节**：Week X

## 问题描述

## 建议改法

## 来源

<!-- 学习过程中在哪个环节发现的 -->
```

## 反馈流程

1. 学习中发现 → 记录到本目录
2. 汇总后提交到 [Handbook GitHub](https://github.com/lxdao-official/aiweb3school) Issue / PR
3. Issue 链接回填到对应 feedback 文件

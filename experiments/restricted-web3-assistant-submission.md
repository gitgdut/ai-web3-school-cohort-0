# 受限 Web3 助手 — 提交说明

> 文件：`experiments/restricted-web3-assistant.html`
> 场景：DeFi Swap（Uniswap V3 模拟）

---

## 1. 解决什么学习问题

Web3 新手最大的困惑之一：**"AI Agent 到底能帮我做什么？又绝对不能做什么？"**

这个 Demo 通过一个实际 Swap 流程，让用户直观感受：
- AI 可以帮你查数据、算汇率、生成预览、验证结果
- 但签名确认那一步 **AI 永远不能代劳**
- 私钥、助记词、API Key 是 AI 绝对不能碰的红线

---

## 2. 用户如何交互

四个步骤，每步都有明确归属标注：

| 步骤 | 内容 | 归属 | 用户操作 |
|------|------|------|----------|
| ① | 用户输入 swap 需求 | — | 打字输入，如「用 500 USDC 换 ETH」 |
| ② | AI 查询池子 + 生成预览 | 🤖 AI 辅助 | 阅读 AI 给出的汇率、滑点、Gas |
| ③ | 🔒 钱包签名确认 | 🔒 必须人工 | **手动点击模拟钱包的「确认」或「拒绝」** |
| ④ | AI 验证交易结果 | 🤖 AI 辅助 | 看 AI 对比预览 vs 实际结果 |

右侧面板实时显示每一步的归属（AI / 人工 / 禁区）。

---

## 3. 输入/输出示例

**输入**：`用 500 USDC 换 ETH`

**AI 输出（步骤 2 — 预览）**：
```
支付：500 USDC
获得：≈ 0.150000 ETH
汇率：1 USDC ≈ 0.0003 ETH
滑点容忍：0.5%
预估 Gas：$3.50
```

**人工操作（步骤 3 — 签名）**：
弹出模拟 MetaMask 弹窗，显示交易详情。
用户必须点击「确认」或「拒绝」。
（如果点拒绝，流程终止，AI 不强行推进）

**AI 输出（步骤 4 — 验证）**：
```
✅ 交易成功
Tx Hash：0xabcd...1234
实际获得：0.149500 ETH
与预览差异：-0.33%（在滑点范围内）
```

## 4. AI 生成 vs 人工修改

### 🤖 AI 全部生成的部分（未修改）
- 完整的 HTML/CSS/JS 结构和样式
- 模拟链上数据查询的延迟和动画
- 交易预览卡片的数据计算逻辑
- 钱包弹窗的 UI 和交互逻辑
- 每一步的气泡消息文案
- 右侧安全面板的归属标注

### 🔧 需要人工验证/修改的部分

| 项目 | 需要验证什么 | 如何验证 |
|------|-------------|----------|
| 概念准确性 | 「受限」的边界定义是否正确 | 对照 Handbook Cryptography 章节关于私钥/签名的说明 |
| 汇率合理性 | 模拟的 USDC/ETH 汇率是否接近真实 | 对比 CoinGecko / Uniswap 实际汇率 |
| UI 可交互性 | 弹窗、按钮、进度条是否正常工作 | 浏览器打开，走完整流程 |
| 文案表达 | 中文术语是否准确（滑点/Gas/签名等） | 对照 Handbook 术语表 |
| 安全边界 | AI 不能做的事是否列全 | 补充：不能管理权限（approve）、不能修改合约 |

## 5. 限制与改进方向

### 当前限制
1. **纯模拟**：不连接任何区块链，池子数据是随机的
2. **单一场景**：只演示了 Swap，没覆盖 NFT 铸造、DAO 投票等
3. **无真实钱包集成**：弹窗是 HTML 模拟的，不是真正的 MetaMask
4. **输入解析简单**：只能识别「数字 + 币种」模式，复杂描述会走默认值
5. **无错误处理**：没模拟交易失败、Gas 不足、滑点超限等异常场景

### 下一步改进
1. 接入真实的链上数据（通过 RPC 只读查询 Uniswap 池子）
2. 增加更多场景：NFT 铸造、代币授权（approve）、DAO 投票
3. 添加「反面教材模式」：展示如果 AI 越权会有什么风险
4. 接入真实钱包（window.ethereum），展示真正的签名流程
5. 添加异常路径：交易失败时 AI 如何帮助你排查

## 1. 它解决什么学习问题

**问题：** 对 DeFi 新手来说，理解去中心化交易所（DEX）的定价机制是一个抽象且困难的概念。Uniswap 等 AMM 协议的恒定乘积公式 `x · y = k` 听起来像数学黑盒——用户不知道：

- 为什么交易价格不是固定的？
- 「滑点」和「价格影响」到底是什么？
- 大额交易为什么比小额交易「更贵」？
- 流动性池的深度如何影响交易体验？

**解决方案：** 这个 demo 把 AMM 的核心机制变成一个**可见、可操作、可试错**的交互式工具。用户不必读白皮书也能通过拖动参数直观理解 AMM 的工作原理。

**学习目标覆盖：**
- 理解恒定乘积公式 `x · y = k` 的数学直觉
- 感受手续费（0.3%）对交易结果的实际影响
- 观察不同交易规模下的价格影响差异
- 建立「流动性深度」与「交易成本」之间的心智模型

## 2. 用户如何与它交互

### 交互流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  ① 设置池参数 │ ──▶ │  ② 输入交易量  │ ──▶ │  ③ 查看结果   │
│  A/B 储备量   │     │  切换方向     │     │  + AI 解释    │
└──────────────┘     └──────────────┘     └──────────────┘
```

### 具体操作

| 操作元素 | 功能 | 反馈 |
|----------|------|------|
| A/B 储备量输入框 | 修改池中两种代币的数量 | 条形图实时变化，k 值同步更新 |
| 交易量输入框 + 快捷按钮 | 输入要交换的代币数量 | — |
| 方向切换箭头 `→` / `←` | 切换 A→B 或 B→A | 面板颜色切换，标签更新 |
| 「模拟交易 + AI 分析」按钮 | 触发计算和分析 | 右侧面板更新结果，AI 打字机式输出解释 |
| 池子可视化条形图 | 显示 A/B 储备比例 | 高度动画过渡，颜色区分代币 |

### 快捷操作
- 点击 100 / 500 / 1000 等按钮快速填入交易量
- 在交易量输入框中按 Enter 直接触发模拟

## 3. 输入示例和输出示例

### 示例 1：小额交易（低价格影响）

**输入：**
- 池中 A 储备：10,000
- 池中 B 储备：30,000
- 交易方向：A → B
- 交易量：100 A

**输出（交易结果）：**

| 指标 | 值 |
|------|-----|
| 你将支付 | 100 A |
| 你将收到 | 295.89 B |
| 实际成交价 | 1 A = 2.96 B |
| 价格影响 | 0.0332% |

**AI 解释摘要：**
> "价格影响非常小。这是一笔小额交易，对池中价格几乎没有影响。"
> 同时解释了 0.3% 手续费扣除逻辑（实际只有 99.7 A 参与交换）。

### 示例 2：大额交易（显著价格影响）

**输入：** 同上池子，但交易量改为 5,000 A

**输出（交易结果）：**

| 指标 | 值 |
|------|-----|
| 你将支付 | 5,000 A |
| 你将收到 | 9,958.23 B |
| 实际成交价 | 1 A = 1.99 B |
| 价格影响 | 33.23% |

**AI 解释摘要：**
> "价格影响非常大！大额交易会在浅池中造成严重的价格偏移。
> 因为你在买入时推高了 A 的供给量，同时又抽走了大量 B，导致 B 变得更稀缺（更贵）。"
> 建议使用聚合器拆分订单。

**关键对比：** 100 A 交易时单价 ≈ 2.96 B，5000 A 交易时单价 ≈ 1.99 B — 用户直观感受到「为什么大单不划算」。

## 5. 限制与下一步改进

### 当前限制

| 限制 | 影响 | 优先级 |
|------|------|--------|
| **AI 解释是模板化的**，非实时 LLM 调用 | 无法处理用户自定义代币名称等灵活输入 | 中 |
| **不支持多池子聚合** | 无法演示 1inch 等聚合器的核心优势 | 低 |
| **无 Gas 费用模拟** | 缺少对链上交易成本的感知 | 中 |
| **固定 0.3% 手续费** | 无法对比不同 DEX 的费率差异（如 Uniswap V3 的多档费率） | 低 |
| **单池子模型** | 无法展示套利、无常损失等进阶概念 | 低 |
| **无音频 / 录屏** | 目前只有静态截图 | 低 |

### 下一步改进方向

1. **接入实时 LLM API**  
   替换 `generateAIExplanation()` 中的模板为 `fetch()` 到 OpenAI / DeepSeek API，让 AI 能根据用户自定义的代币名称、金额生成更个性化的解释。需要处理 API Key 安全问题（服务端代理或环境变量）。

2. **添加「无常损失」模拟模式**  
   增加一个价格变化滑块，演示当外部市场价格变化时，LP（流动性提供者）相对于简单持有会损失多少。

3. **多池子对比视图**  
   并排展示两个不同流动性深度的池子，让用户直观对比同一笔交易在浅池和深池中的价格差异。

4. **Gas 费用估算**  
   添加一个简单的 Gas 计算器（基于当前主网 Gas Price），让用户理解链上交易的总成本 = 价格影响 + 手续费 + Gas。

5. **Uniswap V3 集中流动性**  
   进阶版本：引入价格区间概念，展示 V3 如何通过集中流动性提高资金效率。

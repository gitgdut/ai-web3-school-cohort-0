# AI × Web3 School — Personal Learning Journal

> Personal learning journal and proof-of-work for AI × Web3 School.

## 关于

本仓库是 [AI × Web3 School](https://aiweb3.school) Bootcamp 的个人学习记录仓库。用于记录每日学习、任务完成、实验笔记、Handbook feedback 和项目实践。

- 🎓 **WCB 课程页**：https://web3career.build/zh/programs/AI-Web3-School
- 📋 **WCB Learning**：https://web3career.build/zh/programs/AI-Web3-School#tab=learning

- 🐼 **ETHPanda**：https://ethpanda.org

## 目录结构

```
├── README.md               # 本文件
├── profile.md              # 学员画像
├── learning-plan.md        # 个人学习计划
├── daily/                  # 每日学习笔记 & 打卡草稿
├── tasks/                  # 任务记录
├── experiments/            # 实验 & 原型代码
├── handbook-feedback/      # Handbook 反馈（问题、纠错、建议）
├── hackathon/              # Hackathon 项目
├── submissions/            # 提交材料
└── templates/              # 模板文件
    ├── daily-note.md       # 每日打卡模板
    └── task-note.md        # 任务记录模板
```
